技术栈

构建于成熟开源生态

基于 Flutter 原生框架，结合 libgit2 底层能力与专业渲染库。

🎯

Flutter / Dart 3

跨平台框架，目标 Android，Windows 桌面端用于本机预览调试

🔧

libgit2 FFI

通过 git2dart 实现克隆与 pull 只读能力，后台 isolate 执行避免卡 UI

📝

markdown_widget

Markdown 渲染引擎，配合 flutter_math_fork 实现 KaTeX 公式支持

📈

mermaid_flutter

Mermaid 图表原生渲染，支持 28 种图类型，超宽自动缩放

💾

本地存储

shared_preferences 管理偏好设置，JSON 元数据随仓库存储于 .meta/ 目录

🔌

统一适配层

RepositoryAdapter 抽象层，业务代码不绑定任何 Git 平台 API

快速开始

从源码构建

克隆仓库，安装依赖，即可在设备或模拟器上运行。

bash
git clone https://github.com/interset-wq/pullread.git
cd reader
flutter pub get

# 运行（连接设备/模拟器）
flutter run

# 构建 release APK (arm64)
flutter build apk --split-per-abi --target-platform android-arm64

立即下载 PullRead
